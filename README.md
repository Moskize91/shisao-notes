# 诗骚集注维护说明

诗骚集注是一个面向公开阅读与持续修订的古典文献注释整理网站。它以《诗经》为当前起点，尝试把分散在古籍、整理本与研究材料中的注释线索，整理成便于检索、对照与继续校订的公共文本。

这不是一部一次性完工的“定本”，而是一项长期推进的开放工作。古典文献整理天然会遇到异文、断句、出处、引文、版本差异与理解分歧；与其把这些问题藏在幕后，不如把过程公开出来，让网站本身成为一个可以不断修订、逐步增补的工作现场。

## 维护目标

- 让读者能较快进入原文、注释与相关解释的阅读现场。
- 让整理结果尽量做到可追溯、可核对、可继续修订。
- 让零散的勘误、补充与讨论能够沉淀下来，而不是停留在临时交流里。

## 维护原则

- 以公开可核对的文献与资料为基础，不凭印象补写内容。
- 尽量忠于原始材料的层次与语气，不把整理者说明混入原注。
- 区分原文、引文、摘录、整理与说明，避免不同性质的内容混成一层。
- 数字化工具可以用于检索、初步整理与校对辅助，但不直接把机器输出视为定稿。
- 宁可分阶段逐步补齐，也不追求一次性铺满全部内容。
- 对存在争议或尚待核实的问题，保留修订空间，不轻率下最后判断。

## 维护的方式

诗骚集注采用公开维护的方式推进。网站内容会随着资料补充、错字校正、结构调整与读者反馈不断更新。这里，重点不在于制造一份封闭完成品，而在于把修订过程、问题意识与增补方向尽量放到公开环境中，让后来者能够接续，而不是从头重复劳动。

这种维护方式意味着两件事：

- 网站内容会持续变化，今天的版本未必就是最后版本。
- 发现问题并不可耻，关键在于问题能否被指出、核对与修正。

## 欢迎参与的内容

- 勘误：错字、漏字、标点、分段、引文失当等基础问题。
- 校核：出处、版本、引文归属、上下文对应关系等可核对问题。
- 补充：可公开核查的参考资料、旧注线索、研究线索与相关版本信息。
- 反馈：页面阅读体验、检索路径、注释组织方式与说明表达上的问题。

如果你发现疏漏，或愿意补充线索、提出修订建议，欢迎通过公开渠道反馈。对这类古典整理工作来说，哪怕只是指出一个字、一条出处、一个分段问题，也都是真正有效的贡献。

## 一点说明

诗骚集注希望尽量做得可靠，但它并不自居为不可更动的权威结论。网站中的整理结果，适合用来阅读、检索、比对与继续讨论；若涉及正式研究、出版或严格引用，仍建议回到相应原始文献与整理本核对。

这项工作会长期处在“持续维护中”的状态。也正因此，这项工作的基本方法为：把文本放到公共视野里，把修订留给后来的人。
